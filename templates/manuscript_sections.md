# Nature 风格手稿章节模板

> 本模板按照 Nature 系列期刊的格式要求组织各章节内容。
> 每个章节包含写作要点提示和结构建议。

---

## Title (标题)

**写作要点**:
- 不超过 90 个字符（含空格）
- 避免使用缩写、专业术语和被动语态
- 应清晰传达研究的核心发现或创新点
- 吸引目标读者注意

**结构建议**:
- 格式: [核心发现] + [研究对象/系统] + [方法/机制]
- 示例: "Single-cell analysis reveals cellular heterogeneity in tumor microenvironment"

**草稿**:
```
[在此撰写标题]
```

---

## Abstract (摘要)

**写作要点**:
- 不超过 200 词（Nature 正刊）或 150 词（Nature 子刊）
- 无引用、无缩写、无专业术语
- 结构: 背景(1-2句) → 问题(1句) → 方法(1-2句) → 结果(2-3句) → 结论(1-2句)
- 最后一句强调广泛意义

**结构模板**:
```
[背景: 领域现状和重要性]
[问题: 尚未解决的关键科学问题]
[方法: 本研究采用的核心方法]
[结果: 最重要的发现，包含关键数据]
[结论: 研究意义和影响]
```

**草稿**:
```
[在此撰写摘要]
```

## Main Text (正文)

### Introduction (引言)

**写作要点**:
- 不超过 500 词
- 从广泛背景逐步聚焦到具体问题
- 明确阐述研究缺口和本研究目标
- 避免文献综述式写法，突出逻辑递进

**段落结构**:
1. **第一段**: 大背景 - 为什么这个领域重要？
2. **第二段**: 具体问题 - 目前知道什么？不知道什么？
3. **第三段**: 研究缺口 - 为什么现有知识不足以解决问题？
4. **第四段**: 本研究 - 我们做了什么？假设是什么？

**草稿**:
```
[第一段: 大背景]

[第二段: 具体问题]

[第三段: 研究缺口]

[第四段: 本研究目标]
```

---

### Results (结果)

**写作要点**:
- 按逻辑顺序组织，而非实验顺序
- 每个小节有明确的小标题
- 结果与图表紧密配合
- 避免在结果部分进行讨论
- 使用过去时态描述实验结果

**小节结构建议**:
- 每个结果小节: 2-4 段
- 第一段: 实验设计和主要发现
- 后续段落: 详细数据和统计分析
- 最后一段: 该结果对整体故事的贡献

**小标题示例**:
- "[方法] reveals [发现]"
- "[发现] is associated with [因素]"
- "[干预] modulates [过程] through [机制]"

**草稿**:

#### [结果小节1标题]
```
[第一段: 实验设计和核心发现]

[第二段: 详细数据]

[第三段: 补充分析]
```

#### [结果小节2标题]
```
[内容]
```

#### [结果小节3标题]
```
[内容]
```

---

### Discussion (讨论)

**写作要点**:
- 不超过 800 词
- 以主要发现开头，而非重复结果
- 与现有文献对话，解释一致性和矛盾
- 承认局限性，但不过度强调
- 以广泛意义和未来方向结尾

**段落结构**:
1. **第一段**: 核心发现总结 - 本研究最重要的贡献是什么？
2. **第二段**: 机制解释 - 为什么会观察到这些结果？
3. **第三段**: 与文献比较 - 与前人研究的关系？
4. **第四段**: 优势与局限 - 客观评价研究质量
5. **第五段**: 意义与展望 - 对领域和应用的启示

**草稿**:
```
[第一段: 核心发现]

[第二段: 机制解释]

[第三段: 文献比较]

[第四段: 优势与局限]

[第五段: 意义与展望]
```

### Methods (方法)

**写作要点**:
- 按实验类型分小节
- 提供足够的细节以便重复
- 引用已发表的方法，详细描述修改部分
- 包含统计分析细节
- 使用过去时态

**标准小节**:
- [研究对象/样本]
- [实验设计]
- [数据收集]
- [实验方法1]
- [实验方法2]
- [统计分析]
- [数据可用性]

**草稿**:

#### [方法小节1]
```
[详细描述]
```

#### [方法小节2]
```
[详细描述]
```

#### 统计分析
```
[统计检验方法、软件、显著性标准]
```

## References (参考文献)

**格式要求** (Nature 风格):
- 按出现顺序编号
- 期刊名用标准缩写
- 作者超过5人时列前5人后加 "et al."
- 包含 DOI

**示例格式**:
```
1. Smith, J. et al. Title of the paper. Nature 123, 456-789 (2020).
2. Johnson, A. B. & Lee, C. D. Another paper title. Cell 45, 123-135 (2019).
```

**参考文献列表**:
```
1. [在此添加参考文献]
2. 
3. 
```

## Figure Legends (图例)

**写作要点**:
- 每个图例独立成段
- 首句概括图的核心信息
- 详细说明实验条件和统计方法
- 定义所有缩写和符号

**格式**:
```
Fig. 1 | [核心信息概括].
a, [面板a描述]. b, [面板b描述]. 
[实验条件]. [统计方法]. 
[缩写定义].
```

**草稿**:

**Fig. 1 | [标题]**
```
[详细图例]
```

**Fig. 2 | [标题]**
```
[详细图例]
```

## Tables (表格)

**格式要求**:
- 表题在表格上方
- 使用三线表（顶线、栏目线、底线）
- 注释在表格下方

**示例**:

**Table 1 | [表题]**

| 列1 | 列2 | 列3 |
|-----|-----|-----|
|     |     |     |

[注释说明]

---

## Extended Data (扩展数据)

**说明**: Nature 正刊允许最多 10 个 Extended Data 图/表

**格式**: 与主图相同，编号为 Extended Data Fig. 1, 2, ...

---

## Supplementary Information (补充材料)

**内容**:
- 补充方法细节
- 补充图表
- 补充数据

**格式**: 单独文件，编号为 Supplementary Fig. 1, Supplementary Table 1, ...

## 写作检查清单

### 投稿前检查

- [ ] 标题符合字符限制
- [ ] 摘要符合字数限制
- [ ] 引言逻辑清晰，研究缺口明确
- [ ] 结果与图表对应
- [ ] 讨论不重复结果
- [ ] 方法足够详细
- [ ] 参考文献格式正确
- [ ] 图例完整独立
- [ ] 所有声明完整（数据可用性、利益冲突、作者贡献）
- [ ] 字数符合期刊要求
- [ ] 图表质量符合要求

### 语言检查

- [ ] 无语法错误
- [ ] 无拼写错误
- [ ] 时态使用正确（方法/结果用过去时，结论/普遍真实现时）
- [ ] 主动语态优先
- [ ] 简洁明了，避免冗余
